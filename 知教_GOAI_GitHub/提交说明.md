# 知教 GOAI · 提交说明（汇总版存档）

> 本目录为参赛作品的**重新汇总存档**，约定以 `web/index.html` 为唯一前端入口（以 index 为准）。
> 原目录 `知教_GOAI/` 未做任何改动，保留为历史版本；本目录为独立副本，两者互不影响。

## 一、入口约定（本存档的权威定义）

| 角色 | 文件 | 说明 |
| --- | --- | --- |
| 前端入口 | `web/index.html` | 唯一前端，零依赖单文件；`server.py` 在 `/` 直接服务此文件 |
| 后端 | `server.py` | Python 标准库，ThreadingHTTPServer；端口默认 8000（`PORT` 可换） |
| 启动 | `start.bat` | Windows 一键启动并打开浏览器 |
| 闭环验收 | `tests/verify_loop.py` | 无 Key 可运行：后端启动 + health 结构 + SSE 事件存在性 + 多学科剧本字段完整性 |
| 语法自检 | `tests/check_all.ps1` | 前端 JS 与后端 PY 语法检查 |
| 语音组件 | `tools/asr_live.exe`（+ `asr_live.cs` 源码、`build.ps1` 编译脚本） | Windows 10/11 新一代 DNN 实时语音识别 |
| 提交材料 | `提交材料/` | 早期版本的作品简介（docx）与路演 PPT（pptx），见下方提醒 |

## 二、与旧目录（`知教_GOAI/`）的差异

- **前端收敛为单个 `index.html`**：不再保留 `index-hy3.html`、`index-final.html`、`camera-capture.js` 等并存版本；
- 移除了 `dev/` 开发期调试产物与 `__pycache__/` 缓存；
- `tests/verify_loop.py` 已同步改为校验 `web/index.html`（旧版指向 `index-hy3.html`）；
- `README.md`、`部署说明.md` 中的前端与功能描述已与本目录实现一致。

## 三、运行方式

```bash
cd 知教_GOAI_汇总版
python server.py          # 或 Windows 双击 start.bat
# 浏览器访问 http://localhost:8000
```

- 配置 `DEEPSEEK_API_KEY`（复制 `.env.example` 为 `.env`）→ 真实模型模式；
- 不配置 → 剧本演示模式（离线可复现完整闭环）。
