# 知教 GOAI · 部署说明

## 一、环境要求

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 操作系统 | Windows 10+ / macOS / Linux | 已在 Windows 验证 |
| Python | 3.8 及以上 | 仅使用标准库，无需 pip install 任何包 |
| 浏览器 | Chrome / Edge 最新版 | 语音提问需 Chrome/Edge（支持麦克风权限） |
| 语音识别 | Windows 自带，无需额外安装 | Windows 下优先新一代 DNN 引擎实时识别（asr_live），降级为 SAPI 离线转写 + LLM 纠错；其它系统回退 Web Speech API（需联网） |
| 网络 | 真实模型模式需外网 | 剧本演示模式完全离线可用 |

## 二、启动步骤

### 方式一：一键启动（Windows）

双击 `start.bat`，脚本会自动启动服务并打开浏览器。

### 方式二：命令行启动（全平台）

```bash
cd 知教_GOAI

# 可选：配置 DeepSeek API Key（不配置则自动使用剧本演示模式）
# 方式 A（推荐）：启动后在页面左栏「配置模型 Key」直接填入（仅存服务内存，重启后需重填）
# 方式 B：Windows 下将 .env.example 复制为 .env，编辑填入 Key（持久生效）
# Key 获取：https://platform.deepseek.com

python server.py
```

看到以下输出即启动成功：

```
========================================================
 知教 GOAI 后端已启动
 前端地址：http://localhost:8000
 模型：deepseek-v4-flash
 DeepSeek API Key：已配置（真实模型模式）
========================================================
```

浏览器访问 `http://localhost:8000`。

## 三、两种运行模式说明

| 模式 | 触发条件 | 行为 |
| --- | --- | --- |
| 真实模型模式 | `.env` 中配置了有效的 `DEEPSEEK_API_KEY` | 诊断摘要 / 回复 / 练习卡 / 画像均由 DeepSeek 实时生成，流式输出；自由提问可用 |
| 剧本演示模式 | 未配置 Key、后端未启动或接口异常 | 仅提供预设教学案例（均标注「预设演示案例」）；自由输入如实提示需启动真实模型，不套用无关剧本 |

设计原则：**真实模式下后端失败绝不回退剧本伪造回答**（界面如实提示错误）；剧本模式仅用于无网络 / 无 Key 环境的可复现演示，且预设内容与实时 AI 判断明确区分。其他边界：当前版本图片不经过视觉模型理解（上传后引导口述题意）；剧本模式下年级切换不改变案例内容（案例标注适用年级）；跨学科在剧本模式为预设提示、真实模式为动态联合提问；本项目不提供未经测试的准确率/通过率/学习效果结论。

## 四、环境变量

| 变量 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `DEEPSEEK_API_KEY` | 否 | 空 | DeepSeek 平台 API Key |
| `DEEPSEEK_MODEL` | 否 | `deepseek-v4-flash` | 可换成 DeepSeek V4 系列（`deepseek-v4-flash` / `deepseek-v4-pro`）或其它兼容模型；旧名 `deepseek-chat` / `deepseek-reasoner` 已于 2026-07-24 停用，服务端会自动迁移 |
| `PORT` | 否 | `8000` | 服务端口 |

`.env` 读取顺序：环境变量 → `知教_GOAI/.env` → 仓库根目录 `.env`。

## 五、接口说明

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/health` | GET | 返回 `{"loaded": true/false, "model": ..., "asr": true/false, "asr_live": true/false}`（asr_live=true 表示新一代 DNN 实时识别可用） |
| `/api/chat` | POST | multipart：text / grade / subject / profile / files；返回 SSE |
| `/api/asr` | POST | body 为 16kHz/16bit/单声道 WAV；返回 `{"ok": true/false, "text": ...}`，Windows 下由系统 SAPI 离线转写 + LLM 纠错 |
| `/api/asr_live/start`、`/api/asr_live/stop` | POST | 实时识别会话：start 启动 DNN 引擎聆听麦克风，stop 返回拼接转写文本（经 LLM 纠错） |
| `/api/reset` | POST | 清空服务端会话上下文 |

SSE 事件流：`event: reason`（「为什么这样教」结构化摘要 JSON：观察证据/策略/下一步验证）→ `data:` 增量文本 → `event: quiz`（自主验证选择题 JSON）→ `event: profile`（学习画像 JSON）→ `event: done`。

## 六、常见故障

| 现象 | 原因与处理 |
| --- | --- |
| 端口被占用 | 换端口：`set PORT=8001 && python server.py`（PowerShell：`$env:PORT=8001; python server.py`）。注意某些 IDE 会占用 8000，若页面空白/请求超时优先怀疑端口冲突 |
| 双击 index.html 直接打开 | 可用（剧本模式）；前端会扫描本机端口找后端，找不到则进入剧本演示且控制台无报错。语音提问除外：`file://` 下 Edge/Chrome 可能返回 `not-allowed`，请改用 `start.bat` |
| 回复区显示「模型服务异常」 | Key 无效或余额不足；检查 `.env` 与 DeepSeek 平台账户 |
| 语音提问不可用 | 先双击 `start.bat`，确认地址是 `http://localhost:8000`，再使用语音；不要从 `file://` 页面直接录音。仍不可用时检查系统麦克风权限；识别不到内容会提示「没有听清」，可靠近麦克风重试或改用文字输入。若提示「本机未安装可用的中文语音识别引擎」，页面会自动改用浏览器实时语音识别（需联网）；如需真正离线识别，可在 Windows 设置→时间和语言→语言→中文（简体）→选项 中安装「语音识别」组件后重启服务 |
| 上传图片不可用 | 检查文件是否为图片格式（jpg/png/bmp/webp）且小于 8MB；离线 OCR 提取失败时会自动请学生口述题意，流程不受影响 |
| 乱码 | Windows 请通过 `start.bat` 启动（已设置 UTF-8 代码页） |

## 八、模型 / 存储等新功能说明

- **配置模型（提供方管理）**：页面左栏「配置模型」→ 预设（DeepSeek / 通义千问 / Kimi / 智谱 GLM / Ollama）只填 Key，或自定义（Provider ID / 显示名称 / API 地址 / API 协议（OpenAI 兼容或 Anthropic 兼容）/ 模型名 / API 密钥 / 是否支持图片输入）；支持「设为当前 / 测试连接 / 删除」。配置存于本机 `providers.json`（已被 `.gitignore` 排除，不随代码提交）。
- **题目图片**：上传图片默认走离线 OCR（`tools/ocr.exe`，Windows.Media.Ocr）提取题面文字进模型；识别不到或工具缺失时如实请学生口述题意。若当前提供方勾选了“多模态”，图片会以 base64 直接发给视觉模型。
- **服务端会话存档**：本地学习记录会自动同步到 `sessions.json`（本机，已被 `.gitignore` 排除）；换浏览器 / 换机器访问同一服务时，若本地无数据会自动从服务端恢复。
- **轻量 RAG**：内置 `kb.json` 学科知识卡，按关键词命中注入模型上下文（“学科知识参考”）；可自行增删卡片扩展。
- **练习卡三层质检**：结构校验（≥2 选项且恰 1 正确）→ 语义唯一性（多解拦截，并给出“承认多解”兜底引导后重出）→ 年级难度审核（超纲/过易自动重出），不合格宁可不发。
- **语音三级降级**：Windows 新一代 DNN 实时识别（`tools/asr_live.exe`）→ SAPI 离线转写（`System.Speech`）→ 浏览器 Web Speech；引擎缺失自动降级，页面提示明确。
- **已移除**：「拍照（调用摄像头）」功能（按需求删除）；题目图片仅通过“上传”进入。

## 七、依赖清单

- Python 3 标准库：`http.server`、`urllib.request`、`json`、`re`、`threading`、`pathlib`、`subprocess`
- 系统自带组件（仅语音识别，可选）：Windows 10/11 新一代 DNN 语音引擎（tools/asr_live.exe，WinRT 实时识别）；旧版 SAPI 离线中文识别引擎（通过 PowerShell + System.Speech 调用）
- 浏览器原生 API：Fetch / ReadableStream（SSE）、getUserMedia（麦克风）、localStorage
- 第三方服务：DeepSeek Chat Completions API（商业 API，见《开源协议与边界说明.md》）

无任何 pip / npm 依赖，无构建步骤。
