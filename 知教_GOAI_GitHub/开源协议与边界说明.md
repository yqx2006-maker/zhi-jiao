## 三、第三方依赖与合规声明

### 1. DeepSeek Chat Completions API（商业 API）

- **调用方式**：`server.py` 通过 HTTPS 调用 `https://api.deepseek.com/v1/chat/completions`（OpenAI 兼容协议），使用参赛者自有的 API Key，按 DeepSeek 平台计量计费。
- **模型**：默认 `deepseek-v4-flash`（DeepSeek V4 系列；旧名 `deepseek-chat` 已于 2026-07-24 停用，服务端自动迁移）。DeepSeek 系列模型权重本身以 MIT 协议开源；本项目以托管 API 形式调用，不涉及模型权重的分发与再许可。
- **使用边界**：Key 仅保存在本地 `.env`，不随代码提交；评审可替换为自己的 Key 复现，也可不配置 Key 使用离线剧本演示模式。
- **合规**：调用行为遵守 DeepSeek 开放平台服务条款；生成内容用于教学演示，不涉及模型微调、蒸馏或转售。

### 2. 浏览器原生 API

Web Speech API（语音转写）、getUserMedia（麦克风）、localStorage（学习记录）均为浏览器内置能力，无第三方代码引入。

### 3. Python 标准库

仅使用 Python 官方标准库，遵守 Python Software Foundation License，无分发义务。

## 四、数据与隐私说明

1. 知教仅收集**年级与学科**信息，不收集姓名、学校、照片等任何身份数据；
2. 对话内容仅用于当次会话的教学推理，服务端会话内存随 `/api/reset` 或进程结束清空，不做持久化存储；
3. 前端学习记录仅存于浏览器本地 localStorage，不上传；
4. 不接入任何埋点、统计或广告 SDK。

## 五、知识产权声明

本项目为参赛者独立开发，未抄袭其它参赛作品；使用的第三方服务（DeepSeek API）与浏览器能力均已在上文注明来源、许可与使用边界；演示所用的数学教学内容（一次函数斜率概念）属于公共学科知识。

## 六、适龄内容与未成年人保护

本产品目标用户含**未成年中小学生**，特作如下合规承诺：

1. **内容适龄**：系统提示词明确要求语言贴合学生年级、句子简短、不使用超出学段的术语；不生成暴力、色情、赌博、自伤等不适内容。
2. **不收集未成年人身份信息**：仅采集年级与学科（不含姓名、学校、年龄、联系方式、人脸等可识别信息）；不上传任何身份数据。
3. **无商业化诱导**：不向未成年人推送付费、广告或外链；不设计成瘾机制。
4. **监护人可见性**：学习画像仅存于本地浏览器，家长 / 学生本人可随时通过「清空会话」或清除浏览器数据移除。
5. **能力边界透明**：预设剧本与实时 AI 判断明确区分（前端徽章标注），不向未成年人伪装「预设内容」为「实时智能」，避免误导。
