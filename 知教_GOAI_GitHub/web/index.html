配置 DeepSeek API Key

填入后自动切换到「真实模型模式」。Key 仅保存在本机服务内存中，不写入 .env、不随代码提交；服务重启后需重新填入。也可编辑项目根目录的 .env 后重启服务。

配置模型

选择当前使用的模型提供方，或添加自定义提供方。Key 仅保存在本机 providers.json，不随代码提交；切换后顶栏徽章会更新。
