# 知教 · 评审演示脚本（90 秒主流程 + 进阶项）

> 适用：本机 Chrome + 已联网 + 已配置模型提供方。全程按此顺序即可完整展示“可演示、可验证的闭环”。

## 0. 启动（30 秒）

1. 双击 `start.bat`（或 `python server.py`），看到控制台输出 `前端地址：http://localhost:8000`；
2. 浏览器打开 **http://localhost:8000**（不要用 file://），若曾打开过请 Ctrl+F5 强刷；
3. 顶栏左侧「配置模型」→ 预设选 **DeepSeek** → 粘贴 Key →「添加并使用」→ 显示 `✅ 连接正常`；顶栏徽章变为 **“实时模型 · DeepSeek”**。

## 1. 主闭环（约 90 秒）

1. 点首屏 **「▶ 开始 90 秒完整演示」**：滑块选 k →「用这个例子向我讲解」；
2. 观察顺序：流式文字 →「为什么这样教」卡片（观察证据/策略/下一步）→ 练习卡；
3. 作答练习卡：答对 → 知教确认并**自动出下一题**；右栏「学习画像」阶段推进（定位卡点 → 引导验证）；
4. 展开「为什么这样教」：评审可核对诊断→教学→画像三环节联动（剧本模式会标注“预设策略”）。

## 2. 进阶验证（评审追问时展示）

| 验证点 | 操作 | 预期 |
| --- | --- | --- |
| 真实模型自由提问 | 输入“我刚上初二，初一数学很差怎么学” | 追问给 2-3 个选项 + 开放邀请，不直接灌答案；知识参考命中学习方法卡 |
| 练习卡质检 | 连续作答 | 仅出现“唯一正确答案”的题；多解/超纲题会被拦截重出或提示 |
| 题目图片 OCR | 「添加 → 上传题目图片」选一张带文字的题图 | 对话中出现“离线 OCR 提取”的文字，模型据此引导 |
| 多模态（可选） | 配置一个支持视觉的提供方并勾选“多模态” | 图片直接进模型 |
| 语音提问 | 点「语音提问」→ 说话 | 自动选择可用引擎（DNN/SAPI/浏览器识别）并转写 |
| 会话记忆 | 刷新页面 | 提示“已恢复上次的学习会话”，对话/画像还在 |
| 换浏览器恢复 | 用另一浏览器打开同一地址（本地无数据） | 提示“已从服务端恢复学习记录” |
| 多模型切换 | 「配置模型」添加通义/Kimi 并「设为当前」 | 顶栏徽章更新，可继续对话 |
| 剧本兜底 | 清除 Key 后刷新 | 徽章变“剧本演示模式”，90 秒演示仍可完整跑通 |
| 主题切换/暗色 | 顶栏主题按钮 | 亮/暗/跟随系统三档，暗色下文字清晰 |

## 3. 可复现性

- 无 Key 环境：`python tests/verify_loop.py`（后端启动/health/SSE 事件/多学科剧本字段）应 5/5 通过；
- 语法自检：`tests/check_all.ps1` 应输出 JS/PY SYNTAX OK。

## 4. 常见翻车点（先自查）

- 8000 被旧进程占用 → 先关闭旧 `server.py` 窗口再启动；
- 页面用 file:// 打开 → 统一用 http://localhost:8000；
- 徽章仍是“剧本演示” → 提供方未配置或 Key 无效（用「测试连接」定位）；
- 语音不识别 → 麦克风权限 / 引擎自动降级（页面有提示）。
